# 期末主任务：全自动循线

本仓库用于机器人小组项目期末主任务的七人协作开发。目标是让 RoboMaster 在无人工干预的情况下沿彩色路线行驶，并完成视觉标记识别、红绿灯处理、岔路选择、障碍物避让和断线恢复。

## 任务拆分

| 模块 | 主要内容 | 负责人 |
|---|---|---|
| 任务 1 | 识别 ID 1–5 的视觉标记、云台对准、保存标记截图 | 成员 1 |
| 任务 2 | 识别红绿灯，红灯停车、绿灯继续，保存截图 | 成员 2 |
| 任务 3 | 根据岔路交通灯选择绿灯对应道路 | 成员 3 |
| 任务 4 | 检测道路堵车并选择没有堵车的道路 | 成员 4 |
| 任务 5 | 提前检测障碍物，停车观察，选择左右绕行并回到路线 | 成员 5 |
| 任务 6 | 检测断线、搜索后续彩色路线并恢复循线 | 成员 6 |
| 主控与集成 | 循线主循环、模块优先级、SDK 连接、测试与集成 | 成员 7 |

成员姓名可由小组在提交前补充。每位成员应在独立函数中实现自己的模块，并由主程序调用；提交时同时保留个人代码截图和任务证据截图。

## 当前代码结构

- `run_robot.py`：程序入口和任务优先级协调。
- `line_follower.py`：蓝线检测、PID 循线和断线搜索。
- `marker_detection.py`：指定视觉标记检测、云台对准和截图。
- `traffic_light.py`：红绿灯检测、停车和启动。
- `infrared_detector.py`：原有红外检测版本，主要用于检测目标机器人后停车。
- `obstacle_avoider.py`：任务 5 的避障状态机。
- `pid_controller.py`：PID 控制器。
- `config.py`：阈值和照片目录等参数。

## 任务 5 说明

`obstacle_avoider.py` 使用 RoboMaster 红外距离传感器触发避障流程。检测到近距离目标后，机器人先停车观察，再根据相机下半部分左右区域的边缘密度估计较空的一侧，保存带有 `Team 8 detects obstacle on the left/right way` 的证据图，随后执行横移、前进和反向横移，最后把底盘控制权交还给循线模块。

避障距离阈值、横移速度和持续时间需要在实际赛道上标定。实机测试时应确认障碍物没有被撞到、机器人回到彩色路线，并保留最终截图和视频作为验收证据。

## 使用方式

1. 安装 RoboMaster Python SDK、OpenCV 和 NumPy。
2. 将机器人切换到 AP 模式，并确认电脑已经连接机器人网络。
3. 将同一目录下的模块加入 Python 搜索路径。
4. 运行：

   ```bash
   python run_robot.py
   ```

5. 照片默认保存到 `photos/`，也可以通过环境变量 `ROBOT_PHOTO_DIR` 指定目录。

## 协作约定

- 每个任务使用独立函数或类，避免直接修改其他成员模块。
- 提交前先进行语法检查和模拟测试，再进行实机测试。
- 提交信息使用清楚的中文说明，例如“完善任务 5 停车与左侧绕行”。
- 合并前在主程序中确认模块已经实际调用，并记录对应截图和视频。
- 不要提交个人账号令牌、Wi-Fi 密码或临时照片。

## 评分要点

主任务重点检查机器人是否全自动完成路线和各项任务。截图是任务验收凭证，必须包含检测框、队伍编号、目标类型、灯色、选择方向或恢复路线等说明文字。个人成绩还取决于本人编写的函数是否清楚、是否被主程序实际调用。
